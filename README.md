# Сложно сосредоточиться

Тематическая страница-статья о том, почему нам бывает так сложно сконцентрироваться, особенно когда это очень нужно.

## О проекте

Одностраничный сайт с переключаемыми темами оформления, который помогает разобраться, как строить адаптивные интерфейсы, работать с CSS-переменными и менять оформление в зависимости от системных настроек пользователя.

## Возможности

- **Три темы оформления** — «День», «Авто» и «Неон» — переключаются через меню в шапке сайта;
- **Адаптивная вёрстка** — корректно отображается на мобильных устройствах, планшетах и десктопах;
- **Учёт системных настроек** — тема «Авто» автоматически подстраивается под выбранную тему операционной системы через `prefers-color-scheme`;
- **Декоративные элементы** — анимированные уголки рамок, метка `REC`, декоративные рисунки.

## Технологии

- HTML5
- CSS3 (переменные, медиазапросы, `prefers-color-scheme`)
- JavaScript (для переключения тем)

## Структура проекта

```
slozhno-sosredotochitsya-fd/
├── fonts/                 # подключённые шрифты IBMPlexMono
├── images/                # изображения и иконки
├── scripts/
│   └── script.js          # логика переключения тем
├── styles/
│   ├── globals.css        # базовые стили и сброс
│   ├── variables.css      # CSS-переменные
│   ├── style.css          # основная вёрстка
│   ├── dark.css           # тёмная («неоновая») тема
│   └── light.css          # светлая («дневная») тема
└── index.html             # главная страница
```

## Что внутри

Разделы страницы рассказывают о причинах сложностей с концентрацией: многозадачности, прокрастинации, дофамине и других — с советами, как вернуть себе фокус.
